# פונקט פארקערט — POC שני מסכים סינכרוניים

הוכחת היתכנות למערכת הטריוויה: חלון ניהול + חלון קהל על אותו מחשב, מסונכרנים בזמן אמת.
היקף מלא: ראו `POC_PLAN.md`. תכנון המערכת המלאה: `PLAN.md` בריפו `trivia-event-system`.

## הרצה

```bash
npm install
npm run dev
```

ואז לפתוח בדפדפן: `http://localhost:5173`

- **מסך ניהול:** `http://localhost:5173/admin` — בחלון על המסך שלכם.
- **מסך קהל:** `http://localhost:5173/display` — בחלון נפרד, לגרור למסך השני ולעבור למסך מלא (F11).

## מה יש כאן

- סנכרון מיידי בין החלונות (BroadcastChannel, ללא שרת).
- 5 שחקני דמו, 10 שאלות דמו (קבועים בקוד — בכוונה; ניהול תוכן מלא ייבנה במערכת האמיתית).
- כפתורי נכון/שגוי עם ניקוד ומעבר תור אוטומטי.
- טיימר 2:00 עם השהיה/המשך — בזמן השהיה כפתורי התשובות נחסמים ומסך הקהל מציג "הפסקה".
- פאנל ניקוד ידני (±1) לכל שחקן.
- כפתור "חזור" (Undo) שמבטל את הפעולה האחרונה כולל ניקוד.
- שרידות מלאה: רענון של כל חלון (או הפסקת חשמל) מחזיר בדיוק לאותו מצב; טיימר חוזר מושהה.

## בדיקות

הפרויקט נבדק בבדיקת קצה-לקצה אוטומטית (Playwright, 21 בדיקות) המדמה שני חלונות: סנכרון, ניקוד, טיימר, השהיה, Undo, רענון ואיפוס.
